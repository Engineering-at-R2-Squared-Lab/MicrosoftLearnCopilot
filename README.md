## Meet Copilot Pathways

**Copilot Pathways** is your AI-powered guide to mastering Microsoft products, built on Azure AI.

- **Retrieval-Augmented Generation (RAG)** and **Function Calling**: Fetches the latest insights from the Microsoft Learn Public API, delivering precise, tailored learning paths just for you.
- **Covers Azure, Dynamics 365, Power Platform, and more**: Simplifies complex concepts, helping you learn faster and smarter.
- **Track your progress, earn badges, and unlock new skills**: With Copilot Pathways, mastering Microsoft has never been easier.
